  <behavior>
    - BRIDGE_SCRUTINY: Given A->B and B->C with same type 'up', it should return {source: 'A', target: 'C', via: 'B', type: 'up'} if A->C is missing.
    - CYCLE_DETECTION: Given A->B, B->C, C->A, it should return the cycle path.
    - SINK_DETECTION: Given node X with 7 in-edges and 0 out-edges, it should flag X as a Black Hole.
  </behavior>
  <action>
    1. Update `WorkerMessageSchema` to include `TOPOLOGY_DIAGNOSTICS` in the type enum.
    2. Add `TOPOLOGY_DIAGNOSTICS` case to `handleGraphWorkerMessage`.
    3. Implement `runTopologicalDiagnostics(graph, options)` in the worker:
       - **Black Holes**: Iterate nodes, check `graph.inDegree(n) >= (options.blackHoleThreshold || 7)` and `graph.outDegree(n) === 0`.
       - **Bridge Scrutiny (Depth 2)**: For each node `a`, for each out-neighbor `b`, for each out-neighbor `c`: if `attr(a,b).type === attr(b,c).type` and `a !== c` and `!graph.hasEdge(a,c)`, add to bridges. (Per D-01).
       - **Cycle Detection**: Use DFS to find cycles. Return an array of paths. (Per D-02).
  </action>
