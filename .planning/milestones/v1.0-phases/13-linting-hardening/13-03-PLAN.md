<objective>
Eliminate the remaining `any` casts and unsafe type assertions in the core worker layer, the reactive dashboard store, and the 3-D graph visualiser, bringing the entire `src/` tree to zero `@typescript-eslint/no-explicit-any` warnings.

**Purpose:** Achieve full TypeScript strictness alignment with Obsidian plugin review standards and reduce the crash surface exposed by untyped data flowing across worker thread boundaries.

**Output:**

- `src/core/workers/graph-analysis-core.ts` — worker actions typed with a discriminated union.
- `src/views/dashboard/DashboardStore.svelte.ts` — store state shaped by explicit interfaces; `as any` removed.
- `src/views/GraphVisualizerView.ts` — node/link callbacks typed; `any` disappeared.
- `src/types.ts` — shared interfaces exported for worker and dashboard contracts.
