<task type="auto">
  <name>Implement Reactive DashboardStore with Real-time Sync</name>
  <files>src/views/dashboard/DashboardStore.svelte.ts</files>
  <action>
    Create a class-based Svelte Store in `src/views/dashboard/DashboardStore.svelte.ts`.

    Requirements:
    - Use `#suggestions = $state<Suggestion[]>([])` to hold the list.
    - Implement a `refresh()` method that sets `#suggestions` to a copy of `plugin.cache.suggestions`.
    - **Real-time Sync:** In the constructor, subscribe to the plugin's event emitter (e.g., `plugin.context.on('suggestions-updated', () => this.refresh())`). per RESEARCH.md/D-01.
    - Provide `$derived` getters for the following categories:
      - `structuralGaps`: `id.startsWith('bridge_gap')`
      - `logicLoops`: `id.startsWith('cycle_')`
      - `blackHoles`: `id.startsWith('sink_')`
      - `aiSuggestions`: `type === 'ai'`
    - Expose `suggestions` getter.
    - Expose `history` from `plugin.cache.history`.

    Pattern:
    ```typescript
    export class DashboardStore {
      #suggestions = $state<Suggestion[]>([]);
      constructor(private plugin: SemanticGraphHealer) {
        this.refresh();
        // Event sync per D-01
        this.plugin.registerEvent(
          this.plugin.app.workspace.on('semantic-graph:updated', () => this.refresh())
        );
      }
      refresh() {
        this.#suggestions = [...this.plugin.cache.suggestions];
      }
      get suggestions() { return this.#suggestions; }
      // ... derived getters
    }
    ```

  </action>

  </verify>
  <done>Reactive store implemented with real-time event subscription.</done>
