### Covered Scenarios:

1. **Majority Detection**: Correctly identifies when a tag is present in a majority (>= threshold) of children.
2. **Exclusion List**: Filters out tags matching the exclusion list (case-insensitive).
3. **Nested Tag Handling**: Handles hierarchical tags (e.g., `#science/biology` matches `#science`).
4. **Cluster Size Guard**: Skips clusters with fewer than two children to ensure statistical relevance.
5. **100% Coverage Guard**: Does not suggest tags that are already present in all children.
6. **AI Validation (YES/NO)**: Correctly parses LLM response for tag inheritance validity.
7. **Validation Caching**: Ensures LLM calls are cached to save tokens and improve performance.
