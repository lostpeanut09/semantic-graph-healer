# Plan 14-01: Environment Enforcement & Dependencies

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Establish strict environment constraints and install foundational cross-platform utilities.

**Architecture:**

- Declarative `engines` in `package.json`.
- `.node-version` for automatic toolchain selection.
- `pathe` for consistent pathing.

**Tech Stack:**

- Node.js >= 24.0.0
- npm >= 11.0.0
- pathe

---

### Task 1: Update package.json Engines

**Files:**

- Modify: `package.json`

**Step 1: Add engines field**

```json
{
    "engines": {
        "node": ">=24.0.0",
        "npm": ">=11.0.0"
    }
}
```

**Step 2: Verify npm install fails with wrong version (simulation)**

Run: `node -e "if (process.version.startsWith('v22')) process.exit(0); else process.exit(1)"` (to check if we are on 22 for test)
Run: `npm install --install-links` (should warning or fail depending on config)

**Step 3: Commit**

```bash
git add package.json
git commit -m "chore: add node and npm engine constraints"
```
