# Plan 14-02: Path Normalization

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Replace manual path manipulation with `pathe` for consistent POSIX-style behavior across Windows and WSL.

**Architecture:**

- Use `pathe.join`, `pathe.dirname`, `pathe.basename`, and `pathe.normalize`.
- Ensure all paths generated or manipulated within the plugin use forward slashes.

**Tech Stack:**

- pathe

---

### Task 1: Audit and Replace in DataAdapter

**Files:**

- Modify: `src/core/DataAdapter.ts`

**Step 1: Import pathe**

```typescript
import { join, basename, dirname } from 'pathe';
```

**Step 2: Replace manual split/pop/replace**

```typescript
// Old
const targetBase = f.split('/').pop()?.replace('.ajson', '') || f;
// New
const targetBase = basename(f, '.ajson');
```

**Step 3: Run tests**

Run: `npm test tests/core/adapters/DatacoreAdapter.test.ts`
Expected: PASS

**Step 4: Commit**

```bash
git add src/core/DataAdapter.ts
git commit -m "refactor: use pathe in DataAdapter"
```
