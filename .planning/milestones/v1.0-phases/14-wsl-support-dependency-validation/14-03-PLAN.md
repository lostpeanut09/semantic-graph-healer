### Task 4: Add verify-platform-agnostic CI Job

**Files:**

- Modify: `.github/workflows/quality.yml`

**Step 1: Add new job definition**

```yaml
verify-platform-agnostic:
    name: Platform Agnostic Audit
    runs-on: ubuntu-latest
    steps:
        - uses: actions/checkout@v6
        - name: Scan for Windows-specific separators
          run: |
              ! grep -r "\\\\" src --exclude-dir=node_modules --exclude-dir=.git
```

**Step 2: Commit**

```bash
git add .github/workflows/quality.yml
git commit -m "ci: add platform-agnostic path check"
```
