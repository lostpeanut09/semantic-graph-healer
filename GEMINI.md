# Project Conventions

## Privacy & Security

- **Commit Messages:** Commit messages MUST NOT reference internal planning artifacts, phases, or specific files within the `.planning/` directory (e.g., "phase-19", "PLAN.md", "SUMMARY.md").
- **Generic Messaging:** Commits should focus on the technical or functional change. Remove workflow-specific tags like `(phase-X)` or `(XX-XX)`.
- **Reasoning:** Planning artifacts are internal process details and should not be leaked into the public repository history.
